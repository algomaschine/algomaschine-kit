Audit: is it too good to be true?

A good-looking backtest can be explained by four things other than skill: luck (a short record), the search (the best of many tries always looks good), the market (being long in a rising market) and errors (using information that was not available at the time). The audit applies the tests of the quantitative finance literature, each with a pass rule fixed in code before the results are seen. The Method page explains each one.

How to read it. ✓Pass the result survives the test. !Warn a weakness worth knowing. ✕Fail the test explains the result away. One failure in a core test is enough for "not proven".
